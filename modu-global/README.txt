MODU GLOBAL 모두글로벌 쇼핑몰
=============================

구성

- 국내 결제는 페이플 앱카드로 원화(KRW)를 받습니다.
- 해외 결제는 PayPal Checkout으로 미국 달러(USD)를 받습니다.
- 서버가 저장한 상품 가격과 재고로 결제 총액을 계산합니다. 주문에는 결제
  금액, 통화, 배송 정보와 거래 번호가 저장됩니다. 시연용 상품은 결제할 수 없습니다.

서버 시작

1. Node.js 22.13 이상을 사용하세요. .env.example을 같은 폴더에 .env로
   복사하고 SHOP_ADMIN_PASSWORD에 본인만 아는 16자 이상 비밀번호를 설정하세요.
2. 이 폴더에서 아래 명령을 실행한 후 http://localhost:8080을 여세요.

   node --env-file=.env server.mjs

3. '관리자'에서 로그인하고 판매 상품을 등록하세요. 기존 시연판에서 등록한
   상품이 있으면 기존 관리자에서 JSON으로 백업한 뒤 서버판 관리자에서 복원하세요.
   상품과 주문은 기본값으로 data/shop.sqlite에 저장됩니다.

index.html을 직접 열면 브라우저 저장형 미리보기가 실행됩니다. 이 모드에서는
브랜드, 상품 상세, 장바구니와 관리자 화면을 살펴볼 수 있습니다.

결제사 계정 설정

- 공통. 쇼핑몰 서버를 HTTPS로 연결하고 PUBLIC_ORIGIN을 실제 쇼핑몰 주소로
  설정하세요. 예를 들어 https://shop.example.com과 같이 경로 없이 지정합니다.
  SHOP_DB_PATH에는 재시작 후에도 유지되는 저장소의 SQLite 파일 경로를 지정할 수
  있습니다. 결제 정보와 배송 정보가 저장되므로 이 데이터베이스를 백업하고
  관리자 권한으로 보호하세요. 정식 판매 전 운영사 정보와 배송 정책을 작성하세요.
- 페이플. 계약 후 받는 clientKey, cst_id, custKey를 해당 환경변수에 입력하세요.
  결제창을 호출할 HTTPS 도메인을 페이플에 등록하세요. 국내 배송비와 기본
  과세 여부를 지정하세요. 복합과세 상품은 별도 연동이 필요합니다.
- PayPal. Business 계정의 REST 앱 Client ID 및 Secret을 입력하고 USD 수취를
  설정하세요. 해외 고정 배송비, 판매에 적용할 1 USD당 원화 금액, 배송 가능
  국가 코드를 설정하세요. 결제 버튼을 누르기 전에 USD 결제 금액을 확인할 수
  있습니다. 배송지는 PayPal 화면에서 선택합니다.
- 먼저 각 결제사의 테스트 자격 증명과 sandbox 모드로 연결하세요. PayPal
  Sandbox에서는 테스트 구매자 계정을 사용하세요. 페이플의 국내 카드 테스트는
  실제 카드 승인이 발생할 수 있으므로 가맹점 테스트 절차를 따르세요.
- 테스트 완료 후 라이브 자격 증명으로 바꾸고 해당 결제사의 모드를 live로
  지정하세요. 설정을 바꾸면 서버를 재시작해야 적용됩니다. 운영 배포 전에
  테스트용 주문과 운영 주문의 데이터베이스 파일을 각각 지정하세요.

주문 확인

- 상단 관리자에서 '결제 주문'을 열면 최근 주문, 결제 상태와 배송 정보가
  표시됩니다. 배송은 '결제 완료' 상태를 확인한 뒤 처리하세요.
- 통신 오류 또는 결제사 보류로 결과가 불확실하면 '결제 확인 중'으로 표시되며
  재고가 유지됩니다. '결제 상태 확인'으로 결제사 거래를 조회할 수 있습니다.
  계속 미확인이면 결제사 관리자에서 거래 번호와 승인 여부를 확인하세요.
- 취소·환불과 송장 처리는 각 운영 도구에서 진행합니다. 쇼핑몰의 주문 목록은
  결제 승인 기록을 보여줍니다.
