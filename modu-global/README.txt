MODU GLOBAL 모두글로벌 — 프리미엄 쇼핑몰 디자인 v4
==================================================

시작: index.html을 더블클릭하여 Chrome/Edge 브라우저에서 실행하세요.
PC 및 모바일 반응형, 인터넷 연결 없이도 대부분의 화면이 표시됩니다.
(일부 웹 글꼴은 인터넷 연결 시 로드되며, 미연결 시 기본 글꼴이 적용됩니다.)

브랜드: Care16 / WHANG BIN COSMEDI / HANS LaBelle
브랜드 카드 클릭 -> 상품 목록 -> 상품 상세 -> 장바구니 데모
관리자: 우측 상단 '관리자'에서 브랜드별 상품/사진/가격/재고 등록 및 수정/삭제
* 사진과 데이터는 방문자의 브라우저 localStorage에 저장되며 기기 간 공유되지 않습니다.
* 본 파일은 정식 온라인 쇼핑몰이 아닌 UI / 기능 시연본입니다.
* 실제 PG 결제, 판매자별 정산, 회원가입, 주문/배송, 공유 데이터베이스,
  관리자 로그인/권한 및 보안은 구현되지 않았습니다.
* '시연용 샘플'은 판매용 실제 상품이 아닙니다.
* 정식 운영 시 상품 정보 및 법정 고지 사항을 실제 정보로 교체해야 합니다.

주요 파일
  index.html                메인 사이트 진입
  assets/app.js             브랜드/상품/관리자 기능
  assets/styles.css         기본 디자인
  assets/editorial.css      프리미엄 디자인 v4 (최우선 적용)
  assets/hero-editorial.svg 다운로드 없이 표시되는 편집형 비주얼 이미지
  assets/care16.png         제공 로고 기반 투명 PNG
  assets/whang-bin-cosmedi.png
  assets/hans-labelle.png

원본 로고의 저해상도 특성상 투명화 시 일부 글자 가장자리는 개선이 필요할 수 있습니다.
